Every quarter the hours in our timesheet system and the hours we billed to clients disagree on a few dozen projects. The cause is different every time (late timesheets, wrong project codes, rate changes mid-project) and an analyst spends about two weeks tracing them. We know we've found everything on a project when the differences we can explain add up exactly to the gap. Would an agent be a sensible way to do the tracing?
